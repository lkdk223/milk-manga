# 漫架 · Android 0.3.0

<img src="artwork/icon-master.png" width="112" alt="漫架图标" />

轻小说文库风格的玻璃界面与可滑动立体书架，接入 [Mangabz](https://www.mangabz.com/)，支持本地图片、CBZ／ZIP 和 PDF 漫画。适用于 Android 8.0 及以上。

> **网络提醒：在线看漫画需要开梯子／代理。** 请确保手机上的代理实际覆盖本应用及 Mangabz 的图片域名，仅浏览器能打开网站并不代表应用能加载图片。网络不可达或原站拒绝请求时，预加载也无法解决；本地导入漫画无需联网。

## 安装与使用

从 [Releases](https://github.com/lkdk223/milk-manga/releases/tag/v0.3.0) 下载 `milk-manga-0.3.0.apk`，传到 Android 8.0 或更新的手机，按系统提示安装。与此前试用版包名、签名相同，可覆盖升级保留记录，无需卸载。

- **发现**：展示网站最新更新；在页面顶部向下拖动可刷新最新内容，点「换一批」切换下一页漫画。刷新失败保留当前内容。没有新更新时如实提示。
- **探索**：支持题材、连载／完结和人气／最新更新排序。「排行榜」使用网站人气排序，可筛选题材与状态；不虚构日榜、周榜和评分。
- **书架**：滑动立体书架或切换网格。「检查更新」获取已收藏在线漫画的最新章节和网站更新日期。进入书架时自动检查超过 30 分钟未检查的条目，并发最多 2 个。网络失败保留上次数据。
- **日期**：只显示网站实际提供的日期；原文只有月日时不推断年份，没有日期时显示未提供。检查时间不是章节更新时间。
- **本地导入**：在书架点「导入本地」，通过系统文件选择器选择多张图片，或单个 CBZ／ZIP／PDF。文件复制到应用私有存储后可离线阅读，不依赖原文件继续存在。
- **本地格式**：JPG、PNG、WebP、GIF、BMP 等图片；含图片的 ZIP／CBZ；未加密、系统渲染器支持的 PDF。图片按文件名自然排序，如 1、2、10。PDF 按页渲染。
- **预加载**：阅读第 1 章时自动下载后续第 2–6 章的实际图片；切章复用已获取的图片目录，预加载范围随当前章节向后移动。状态栏显示进度，失败可点击重试；「我的」可关闭预加载。使用当前网络，含移动数据。单独的后台下载队列避免把图片下载排在当前阅读请求前面。
- **缓存**：在线图片使用独立的 512 MiB 磁盘缓存；签名更新复用同一图片路径，超限淘汰较久未用内容，空间不足时仍可在线显示，但不报告缓存成功。章节目录只在当前会话复用，应用重启后需要联网重新获取目录。
- **自动清理**：按手机时区安排每天 03:00 清除在线图片缓存；应用前台每分钟补查，启动及回到前台时补查逾期任务。系统非精确定时、休眠、省电或强制停止可能延后执行；重启、升级、修改时间／时区后重新安排。清理会取消旧的预加载任务，下一次切章或点击状态栏可重新缓冲；本地导入原件、收藏和阅读进度均保留。未申请精确闹钟权限。
- **图标**：依据用户提供的参考图，使用内置 ImageGen 重绘白发蓝眼的素描头像，已应用到自适应桌面图标和应用页眉；原图及提示词见 `artwork/`。
- **阅读**：左右滑动、页码跳转、纵向连续模式、缩放与本机进度保存。

本地导入每本上限 512 MiB、5000 页，单张图片上限 24 MiB。ZIP 不解压到文件系统。当前没有 CBR／RAR、文件夹导入、密码 PDF、手动管理的离线下载任务或跨设备同步。卸载／清除应用数据会删除本机记录和导入副本，请自行保留原文件。

## 验证范围

已完成真实网页样本的分类、分页、最新章节和月日解析；浏览器手机尺寸下的分类／榜单、下拉刷新、换批、刷新失败保留、更新记录、离线本地书籍界面与进度测试；立体书架拖动／吸附回归；Java 图片排序、GB18030 ZIP 文件名、安全条目和中文编码测试；后续 5 章的实际图片下载桥接、切章滑动范围、复用目录、取消／重试／关闭与清理保留记录的浏览器回归；原生磁盘缓存签名复用、大小上限、持久化、系统回收后恢复、并发清理旧写入隔离，以及 03:00 与夏令时日历测试；Android Java 编译、DEX 和 APK 签名校验。

UI 测试使用本地测试图片和受控返回数据，不代表网站图片网络已恢复。尚无连接的安卓真机，系统文件选择器、实际文件复制、PDF 原生渲染和系统后台定时清理仍需手机验证。网站不可直连时，客户端不能保证免代理访问；本地导入无需访问漫画网站。

## 源码与构建

使用系统 WebView 和 Java 标准库，不需要 Flutter、Gradle 或 npm 产品依赖。需要 JDK 17、Android SDK Platform 35、Build Tools 35.0.1，以及 Python 3。

```powershell
python build.py --sdk C:/path/to/android-sdk --jdk C:/path/to/jdk-17
node test_source.cjs
```

构建脚本会在 `.local-signing/` 生成本机开发签名；仓库和源码压缩包均不包含已发布 APK 的签名私钥。自行构建使用不同签名时，不能覆盖安装官方发布包；请先保留原始本地漫画文件，再处理安装冲突。卸载应用会清除应用内的数据与导入副本。

`assets/source.js` 由 `vendor/mangabz.js` 和 `prepare_source.py` 生成，修改图源后运行 `python prepare_source.py`。测试工具见 `checks/`；浏览器检查需要该目录的本地预览服务器和隔离的 Chromium 调试会话。
